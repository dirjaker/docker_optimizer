## ✨ 功能特性

- 问题检测
- 优化建议
- Dockerfile重写
- 体积对比

## 🚀 快速开始

```bash
# 克隆项目
git clone https://github.com/dirjaker/docker_optimizer.git
cd docker_optimizer

# 创建虚拟环境
conda create -n docker_optimizer python=3.12 -y
conda activate docker_optimizer

# 安装依赖
pip install -r requirements.txt

# 运行项目
python main.py
```
